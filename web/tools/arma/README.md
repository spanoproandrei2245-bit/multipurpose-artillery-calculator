# Карта без grad_meh (топо из самой игры)

Нужна, когда `grad_meh` пишет «PBO of WRP couldn't be found» — карта в зашифрованном `.ebo`
(Cam Lao Nam и другие карты DLC). Данные берутся скриптом из загруженной в игре карты,
поэтому **спутникового снимка не будет: в приложении такая карта — только режим «Топо»**
(здания, дороги, горизонтали, названия). Лесов в этом экспорте нет.

## 1. Экспорт в игре

1. Запустите Arma 3 (2.02 или новее), откройте редактор на нужной карте, пустая миссия → «Играть».
2. Esc → Debug Console → вставьте весь файл `web/tools/arma/gradtopo_export.sqf` в поле кода → **Local Exec**. В файле намеренно нет комментариев и кириллицы: консоль игры не понимает `/* */`, `//` и мешает с юникодом.
3. Ждите: в чате идёт прогресс (высоты, потом объекты). Большая карта — 5–20 минут. Игру не сворачивайте.
4. Когда появится «GRADTOPO: done - you can close the game», закройте игру.

Данные записаны в RPT: `%LOCALAPPDATA%\Arma 3\arma3_x64_<дата>.rpt` (берите самый новый файл).
Не запускайте другие экспорты в той же сессии: всё лишнее в RPT пропускается, но файл станет огромным.

## 2. Импорт в приложение (из папки `web/`)

```bash
node scripts/import-rpt.mjs "<путь к .rpt>" "D:/export/cam_lao_nam" --name "Cam Lao Nam" --author "Bohemia Interactive"
node scripts/import-grad-meh.mjs --no-sat "D:/export/cam_lao_nam"
```

Первая команда превращает RPT в папку в формате выгрузки grad_meh (`meta.json`, `dem.asc.gz`, `geojson/`),
вторая добавляет карту в `public/maps/` (без тайлов спутника). Дальше как обычно: `npm run build`, коммит.

## Что в экспорте

| Данные | Откуда | Примечание |
|---|---|---|
| Высоты | `getTerrainHeightASL`, шаг 20 м | горизонтали строятся из них |
| Здания | `nearestTerrainObjects` + `boundingBoxReal` | прямоугольник по границам модели |
| Дороги | `nearRoads` + `getRoadInfo` | отрезки склеиваются в ломаные |
| Названия | `nearestLocations` | города, деревни, холмы, аэродромы |
| Вершины | считаются по высотам | локальные максимумы, не чаще 300 м |

## Права

Карты DLC принадлежат их авторам (Bohemia Interactive / Creator DLC). Перед публикацией такой карты
на сайте нужно разрешение правообладателя.

## Фото карты (необязательно, вместо «голого» топо)

Спутник напрямую взять нельзя, но можно сфотографировать **внутриигровую карту** кусками и склеить.
Результат хуже настоящего спутника grad_meh (разрешение ~1,5 м/px, на карте остаются подписи и сетка),
зато у карты появляется «фото» под зданиями и дорогами.

Команда `screenshot` в игре у многих не сохраняет файлы (в RPT «Saving of screenshot failed: E_FAIL»
или молча ничего), поэтому экран снимает Windows: наблюдатель `capture_screen.ps1` ждёт в RPT строки
скрипта и в этот момент делает снимок экрана.

1. Игра запущена на нужной карте (окно без рамки или оконный режим на основном мониторе).
2. В терминале запустите наблюдателя (он останавливается сам):
   `powershell -ExecutionPolicy Bypass -File web/tools/arma/capture_screen.ps1 -OutDir D:\gradphoto`
3. В игре: Debug Console → вставьте `web/tools/arma/gradtopo_photos.sqf` → **Local Exec**.
   Скрипт откроет полноэкранную карту, сам подберёт масштаб и пройдёт всю карту (около 90–150 кадров).
   Не трогайте мышь и клавиатуру и не сворачивайте игру, пока в чате не появится «GRADPHOTO: done».
4. Кадры лежат в `D:\gradphoto`. Склейка (из папки `web/`), потом обычный импорт — теперь со спутниковым слоем:

```bash
node scripts/import-photos.mjs "<путь к .rpt>" "D:/.../grad_meh/cam_lao_nam" --images "D:/gradphoto" --mpp 2
node scripts/import-grad-meh.mjs "D:/.../grad_meh/cam_lao_nam"
```

Склейка сама убирает линии сетки игры (`--degrid off` отключает) и режет края: подписи сетки стоят по краям
карты, поэтому добавляйте `--crop 16`. Область карты на кадре (в игре карта занимает прямоугольник в центре
экрана) задаётся `--rect x,y,ширина,высота` в пикселях скриншота; для Cam Lao Nam на экране 1920×1080 это
`--rect 566,245,788,590`. Пример полной команды:
`node scripts/import-photos.mjs "<rpt>" "<папка>" --images D:/gradphoto --mpp 4 --rect 566,245,788,590 --crop 16`
Команда `screenshot` и поведение карты зависят от версии игры: если снимки не появились или карта
в кадре не заполняет экран, пришлите последние строки RPT с `GRADPHOTO`.
