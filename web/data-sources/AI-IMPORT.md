# Перепечатка таблиц с помощью любой нейросети

Дорогая модель для этого не нужна: подойдёт любая, которая читает картинки
(Gemini, ChatGPT, Claude Haiku/Sonnet и т. п.). Дальше всё проверяют скрипты.

## Два набора таблиц

| Что снимать | Куда класть | В приложении |
|---|---|---|
| Таблица **без** сопротивления воздуха (обычная) | `data-sources/<id>/HIGH-<заряд>.txt` | по умолчанию |
| Таблица **с** сопротивлением / улучшенной баллистикой | `data-sources/<id>/advanced/HIGH-<заряд>.txt` | настройка «Улучшенная баллистика» |

Снимать оба набора нужно в игре с соответствующей настройкой, на одном орудии и
одном снаряде. Если для орудия `advanced` нет, приложение предупредит и возьмёт обычные.

## Порядок работы

1. Сделайте скриншоты таблицы (один заряд — один или несколько кадров, с перекрытием).
2. Загрузите кадры нейросети вместе с промптом ниже. Если кадров много, делайте по одному заряду.
3. Сохраните ответ нейросети в любой файл, например `answer.txt`.
4. Разрежьте ответ на файлы и проверьте (из папки `web/`):

```bash
node scripts/ingest-tables.mjs split <id> answer.txt            # обычные
node scripts/ingest-tables.mjs split <id> answer.txt --advanced # с сопротивлением
node scripts/ingest-tables.mjs validate <id>                    # (или с --advanced)
```

   `validate` печатает все сомнительные места: лишние/недостающие столбцы,
   «?» вместо цифры, скачки возвышения (признак ошибки распознавания),
   пропущенные строки. Исправьте их по скриншоту прямо в `.txt`.
5. `npm run tables:import`, затем `npm run tables:check` и `npm test`.

`<id>` — `mk6`, `m252_rhsusaf`, `m2_sog`, `m29_sog`, `m101_sog`, `seara` или новый.
Для нового орудия сначала нужен JSON-справочник в `src/data/artillery/`.

## Промпт для нейросети (копировать целиком)

```
Ты перепечатываешь таблицу стрельбы артиллерии из игры Arma 3 (ACE3, меню Artillery Table) со скриншотов.
Точность важнее всего. Ничего не придумывай и не «исправляй» значения, не интерполируй, не достраивай.

Таблица имеет столбцы слева направо:
1 RANGE (м), 2 ELEV (мил), 3 D ELEV PER 100 M DR, 4 TIME OF FLIGHT PER 100 M DR, 5 TIME OF FLIGHT (с),
6 AZIMUTH CORRECTION CROSSWIND OF 1 MPS, 7 RANGE WIND HEAD, 8 RANGE WIND TAIL,
9 AIR TEMP DEC, 10 AIR TEMP INC, 11 AIR DENSITY DEC, 12 AIR DENSITY INC.

Правила вывода:
- Одна строка таблицы = одна строка текста, значения через ОДИН пробел, ровно 12 значений
  (или ровно 5, если в игре столбцы 6–12 пусты — тогда во всех строках по 5).
- Прочерк в игре записывай как - (дефис).
- Десятичная точка — точка. Знак минус сохраняй.
- Если цифру нельзя прочитать уверенно, пиши вместо неё ? (вопросительный знак) — не угадывай.
- Строки в порядке возрастания RANGE. Если кадры перекрываются, повторяющиеся строки выводи один раз.
- Не добавляй пояснений внутри таблицы.

Формат ответа: для каждого заряда заголовок и блок кода, например:

### HIGH-0
```
50 1500 ...
100 1490 ...
```
### HIGH-1
```
...
```

Режим (HIGH/LOW) и номер заряда смотри в игре на кадре (список Charge слева, режим сверху).
Сейчас на кадрах: режим ____, заряды ____.
```

## Если нейросеть ошибается

- Мелкий текст: увеличьте кадр (zoom ×2) или вырежьте нужные столбцы.
- Стабильно путает похожие цифры (1/7, 3/8): снимайте окно игры крупнее, в 4K.
- Любой результат всё равно сверяется `validate` и тестами, но **значения должны совпадать
  со скриншотом** — выборочно сверьте 3–5 строк на каждом заряде.
