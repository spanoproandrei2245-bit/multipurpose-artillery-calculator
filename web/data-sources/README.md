# Источники игровых таблиц

Текстовые копии таблиц ACE3 (меню «Artillery Table»), перепечатанные
со скриншотов игры. Из них генерируются `profiles.<профиль>.modes`
в `web/src/data/artillery/<id>.json` (команды выполняются из `web/`):

```bash
node scripts/import-tables.mjs data-sources/m252_rhsusaf src/data/artillery/m252_rhsusaf.json
```

Проверка без записи — флаг `--check`: скрипт сравнит JSON с текстом
и завершится с ошибкой, если они расходятся.

```bash
npm run tables:check
```

Перепечатку можно поручить любой нейросети: см. [AI-IMPORT.md](AI-IMPORT.md) (промпт, команды `tables:ingest split/validate`, папка `advanced/` для таблиц с сопротивлением воздуха).

## Формат

Папка = один справочник. Файл `<РЕЖИМ>-<заряд>.txt` (например,
`HIGH-2.txt`) — одна строка таблицы на строку файла, столбцы через
пробел, в порядке игры:

| # | Столбец игры | Ед. |
|---|---|---|
| 1 | RANGE | м |
| 2 | ELEV | мил |
| 3 | D ELEV PER 100 M DR | мил |
| 4 | TIME OF FLIGHT PER 100 M DR | с |
| 5 | TIME OF FLIGHT | с |
| 6 | AZIMUTH CORRECTION CROSSWIND OF 1 MPS | мил |
| 7 | RANGE WIND 1 MPS — HEAD | м |
| 8 | RANGE WIND 1 MPS — TAIL | м |
| 9 | AIR TEMP (15° STD) 1 DEG — DEC | м |
| 10 | AIR TEMP (15° STD) 1 DEG — INC | м |
| 11 | AIR DENSITY 1 PCT — DEC | м |
| 12 | AIR DENSITY 1 PCT — INC | м |

- Допускаются строки из 5 столбцов (только 1–5), если погодные
  столбцы в игре пустые.
- Прочерк записывается как `-` и превращается в `null`.
- Строки, начинающиеся с `#`, — комментарии.
- Значения не придумываются: только то, что видно на скриншоте.
  Если таблица на скриншоте обрезана, это отмечается комментарием.
